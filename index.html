    One-time setup on the computer
    1. Download Forge (1.9 GB):
      github.com/lllyasviel/stable-diffusion-webui-forge/releases/download/latest/webui_forge_cu121_torch231.7z
    2. Right-click the downloaded file → Extract All (or use 7-Zip) into a folder like C:\Forge.
    3. In that folder, open webui\webui-user.bat with Notepad and change the set COMMANDLINE_ARGS= line to:
      set COMMANDLINE_ARGS=--api --cors-allow-origins=https://castlebayne.github.io
      Save and close.
    4. Download an image model into webui\models\Stable-diffusion. Fast one (2.1 GB):
      huggingface.co/philz1337x/epicrealism/resolve/main/epicrealism_naturalSinRC1VAE.safetensors
    5. Double-click update.bat once, then run.bat. The first start takes a few minutes. When a browser page for Forge opens, it's ready; leave the black window open.
    6. Back here, open Image settings → Test connection.
